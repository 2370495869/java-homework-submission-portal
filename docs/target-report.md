# 目标报告：课程作业提交平台

## 当前基线（改造前）

当前仓库位于 JAVAshiyan3，分支为 main，尚无 Git 提交，也没有配置 remote；现有项目文件均显示为未跟踪文件。README 与实现报告描述的是一个仅供本机演示的 JDK HttpServer：登录账号/明文密码写在源码中，会话和文件列表在进程内维护，没有课程、教师、作业、数据库或提交版本模型。当前工作目录另有 target/、uploads/ 和 testfiles/；这些运行产物或样例数据不得进入发布提交。

本报告定义改造目标，不代表其中功能已经实现。实际实现和验证状态由后续更新的 docs/implementation-report.md 记录。

## 产品目标

交付一个可独立运行、适合课程展示及公开发布的中文课程作业提交平台。它应有完整的浏览器界面、持久化数据、可重建的数据库结构、本地文件卷，以及无需全局 Maven 安装的构建入口。

### 角色和业务流程

- **管理员**：由部署环境中的一次性引导配置建立；可查看用户并将注册学生设为教师。
- **教师**：创建和管理自己负责的课程、查看课程邀请码、发布作业和截止时间，设置是否接受迟交，并查看课程学生的各次提交。
- **学生**：注册后可用邀请码加入课程；查看作业及截止/迟交规则；按作业提交文件、查看提交状态和历史版本，并下载本人提交。
- 每份作业的每名学生有一条提交记录，每次重新提交产生递增版本；记录提交时间、是否迟交、原始文件名和存储元数据。教师只能管理自己课程的数据，学生只能查看或下载自己的提交。

### 文件和安全目标

- 使用 Spring Security 的服务端会话登录、BCrypt 密码哈希、角色及课程归属授权；保留 CSRF 防护，Cookie 设置 HttpOnly、SameSite，并可配置 HTTPS 下的 Secure 标志。
- 限制单文件大小（目标沿用 10 MiB）、允许的文件类型（PDF、DOC、DOCX）以及上传请求总量；校验扩展名和文件签名，不信任客户端 MIME、文件名或路径。
- 文件名只作为展示元数据保存，磁盘使用随机存储键；下载强制附件响应并对每次下载执行归属授权。
- 通过 FileStorage 接口隔离存储实现，首版使用应用容器外的本地卷；数据库只保存文件元数据和随机键。拒绝路径穿越及同名覆盖。
- 不提交账户密码、访问令牌、真实个人资料、.env、数据库目录、上传内容或构建产物。管理员引导凭据及数据库凭据只从环境变量读取；公开的 .env.example 仅提供待替换占位符。

## 技术方案

- **Java 21 LTS**：与当前本机 Temurin JDK 21 一致，便于本机启动验证；Spring Boot 4.1.1 官方要求 Java 17 起，兼容到 Java 26。
- **Spring Boot 4.1.1**：采用受支持的稳定版本；服务端 MVC + Thymeleaf 组成单体应用，避免发布时依赖独立前端服务。
- **Maven Wrapper 3.3.4 / Maven 3.9.16**：提交标准 Wrapper 文件，不要求开发机预装 Maven。
- **PostgreSQL 18.6**：Compose 使用明确版本标签；数据通过命名卷持久化。Flyway 12.4.0 及 PostgreSQL 模块由 Spring Boot BOM 统一管理。
- **Docker Compose Specification**：定义应用、PostgreSQL、健康检查和独立上传卷；应用等待数据库健康后再启动。
- **GitHub Actions**：用 Wrapper 构建并运行自动化测试，限制工作流只读仓库内容权限。

## 交付与验收标准

1. 首次启动按说明配置环境变量并启动 Compose；数据库结构由 Flyway 自动建立，应用可通过浏览器访问。
2. 学生注册及登录可用；未经授权的角色、课程和文件访问会被拒绝，表单具备 CSRF 保护。
3. 教师可创建课程和作业；学生可通过邀请码加入课程，按迟交规则提交文件并查看版本历史。
4. PDF、DOC、DOCX 可按大小和内容校验规则接收；下载权限、文件卷持久化及上传数据隔离有效。
5. 有覆盖登录权限、课程/作业归属、迟交策略、上传校验和文件存储的自动化检查；构建与启动结果如实记入实现报告。
6. 发布前审阅最终差异及暂存清单，排除秘密、真实个人数据、.env、数据库/上传/构建数据及原始测试样例；仅提交本项目，并将提交推送到新建或已确认归属的公开 main 分支。
